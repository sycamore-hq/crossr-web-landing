One command

Bootstrap from the harness, not the catalog.

Clone crossr-harness and run harness-bootstrap. It installs the pinned catalog and loops. The old crossr-skills/scripts/harness-bootstrap is a shim — it prints deprecation and exits 1.

# Clone and bootstrap a new project
git clone https://github.com/sycamore-hq/crossr-harness.git
./crossr-harness/scripts/harness-bootstrap /path/to/your-project
# Pins (lockfile.toml)
skills = "v0-last-monolith"
loops = "v0"
# graphs/ live on loops main; not in pin v0; bootstrap does not copy them
