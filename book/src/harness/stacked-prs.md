# PETC Loop & Stacked PR Discipline

Ritual law lives in [`crossr-harness` HARNESS-SPEC.md](https://github.com/sycamore-hq/crossr-harness/blob/main/HARNESS-SPEC.md), not here.

Every large effort is decomposed into tiny, reviewable PRs (< 10 minutes deep review). Traceability runs through the project's tracking board: its item ids appear in commits and PR titles, and the record of each increment lives on the item. The harness requires a board and names none — Linear, GitHub Projects, Jira, whatever the project discloses.

This page is a door. It does not duplicate the spec.
